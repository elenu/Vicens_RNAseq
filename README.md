# Vicens_RNAseq

This repository contains the RNA-seq analysis notebooks used in association with the paper published in *American Journal of Physiology - Cell Physiology*:

**DOI:** [10.1152/ajpcell.00098.2025](https://journals.physiology.org/doi/full/10.1152/ajpcell.00098.2025)

## Paper association (summary)

The repository supports the transcriptomic analysis presented in the manuscript, including RNA-seq count processing, tissue-specific transcriptomic processing, and statistical analysis steps used to obtain the reported results.

## Repository contents

- `Counts_processing.Rmd`  
  Processing and preparation of RNA-seq count data for downstream analysis.

- `TMPs_processing_Liver.Rmd`  
  Processing workflow focused on liver transcriptomic data.

- `TMPs_processing_WAT.Rmd`  
  Processing workflow focused on white adipose tissue (WAT) transcriptomic data.

- `Statistics.Rmd`  
  Statistical analyses applied to processed transcriptomic datasets.
